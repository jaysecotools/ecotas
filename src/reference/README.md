# Tasmanian Reference Data

These files provide *advisory* reference lists for common Tasmanian contexts.
They are NOT official registers, do NOT constitute legal advice, and must be
verified against current official sources before any professional reliance.

Each file records:

- `metadata.source` — where the list was compiled from
- `metadata.sourceDate` — the date the source was accessed
- `metadata.caveat` — a plain-language limitation

If you modify these files, keep the metadata honest. Users deserve to know
where a list came from and how stale it is.
