# EcoTas Position on Compliance

EcoTas is **not** a compliance or certification tool. It provides a
configurable checklist mechanism that organisations can use to track their
own obligations under their own frameworks and jurisdictions.

Specifically:

- EcoTas does not assert that any legislation, regulation, standard, or
  training package has been satisfied.
- EcoTas does not bundle a regulatory database.
- Reference lists (weeds, threatened species, vegetation communities) are
  advisory and carry metadata recording their source and date.
- Any user who records a compliance status is responsible for the evidence
  supporting that status.

This position exists because the legacy applications reviewed in Phase 1
conflated a training unit code (AHCECR301) with a compliance framework.
EcoTas explicitly avoids that error.
